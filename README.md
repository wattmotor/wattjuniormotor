# WJM GitHub Pages

Versi statis WATT JUNIOR MOTOR untuk GitHub Pages.

## Hosting
1. Buat repository GitHub.
2. Upload `index.html`, `favicon.png`, dan folder `assets` ke root repository.
3. Buka Settings > Pages.
4. Pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/(root)`.
6. Save.

Website utama tetap berada di https://wattjuniormotor.online/
